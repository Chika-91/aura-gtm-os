## How this folder works
- `.claude/skills/`: reusable skills and prompts. Read before running any repeatable task.
- `context/icp/`: ideal customer profile docs. Read before choosing targets or writing copy.
- `context/positioning/`: positioning and differentiation docs. Read before any messaging work.
- `context/messaging/`: approved messaging, value props, proof points. Read before drafting any copy.
- `context/brand-kit/`: voice, tone, visual and style guidance. Read before producing anything customer-facing.
- `context/docs/research/`: raw research notes with sources. Read when you need a fact, and add new findings here first.
- `knowledge-base/playbooks/`: step-by-step repeatable GTM processes. Read before running a workflow.
- `knowledge-base/learnings/`: what worked, what did not, and why. Read before repeating or changing an approach.
- `meetings/`: meeting notes and transcripts. Read for decisions and open actions.
- `output/campaigns/`: finished campaign assets and copy. Write deliverables here, and read to avoid duplicating work.
- `tools/`: scripts, integrations and tool notes. Read before building something that may already exist.
- `weekly-priorities/`: one file per ISO week with that week's priorities. Read at the start of every session.
- `work-log/`: one file per ISO week logging every change. Read for history, and write to it after every change.

## Rules
- Cite a source (URL or file path) for every company fact.
- Never invent numbers. If a figure is unknown, say so.
- No em dashes in any copy.
- Ask before sending or publishing anything.
- Log every change in this week's work log (`work-log/YYYY-Www.md`).
